# LootGen

**Need a shop’s inventory or a room’s loot in ten seconds?** LootGen is a small helper for tabletop RPGs. Tap a few choices, hit Generate, and you get a list of items you can read out at the table.

This is a fan-made tool for game nights. It is not an official product of any game publisher.

Pick the one that matches the device you will use at the table:

- **[Android](https://github.com/racostyle/LootGen/raw/main/dist/Android/LootGen-1.0.0.apk)** — `dist/Android/LootGen-1.0.0.apk`

### Windows

1. Click the Windows link above and save the zip file.
2. Right-click the zip, choose **Extract All**, and pick a folder you can find again (for example your Desktop).
3. Open the extracted folder and double-click **LootGen**.

You need a 64-bit PC running Windows 10 or Windows 11.

### Android

1. Open this page on your phone and tap the Android link above, or copy the file onto the phone.
2. Open the downloaded file. If Android asks whether you want to install it, say yes.
3. Your phone may warn that the app did not come from the Play Store. That is expected for a file you download yourself. Allow install from this source if you trust this project, then tap **Install**.

LootGen does not need an internet connection once it is installed.

## What it does

During a session you often need answers like:

- “What is this general store selling?”
- “What is in this locker / crate / ruined clinic?”

Instead of flipping through books, you choose the kind of place, how big it is, and how fancy the goods can get. LootGen then rolls a mixed list of items with names, costs, weights, and short notes.

---

## How to use it

1. **Choose a profile** (the game’s item list). Tap the profile button on the home screen, then tap the one you want:
   - **Fallout2d20** — Fallout 2d20 (the default)
   - **Fallout2d20_Alternative** — a second Fallout 2d20 set
   - **Dnd** — Dungeons & Dragons style gear
2. Tap **Generate**.
3. Choose **Merchant** (a shop’s stock) or **Location** (loot found in a place).
4. Tap one or more **types** (weapons, food, chems, armor, and so on). Highlighted types are included.
5. Pick a **size**. Tiny is a small stash. Large is a well-stocked shop or a big haul. Bigger sizes give you more items.
6. Pick the **highest rarity available**. Common shops stay humble. Rare, legendary, or artifact lets richer goods appear.
7. Tap **Generate** and read the list.

Tap Generate again any time you want a fresh roll.

---

## Tips for the table

- A tiny **Merchant** with only food and drinks is a roadside stall. A large merchant with many types selected is a big trading post.
- A **Location** with ammo and chems fits a clinic or raider camp. Mix types to match the room you just described.
- If the list feels too rich, lower the highest rarity and generate again. If it feels thin, raise the size.

---

## Settings

Settings lets you add or remove rarity and size labels. Most people can leave this alone. **Restore defaults** puts the original lists back (it asks you three times so it is hard to do by accident).
